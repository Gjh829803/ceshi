目录归属

从文件到调用

  1. Registry 分页发现内容与固定版本。
  2. Manifests 描述模型、绑定、动画与精确依赖。
  3. Locks 固定所选内容及完整依赖闭包。
  4. Artifacts 按哈希取回并验证字节；相机和控制参数由引擎管理。

接入入口

只需替换库的 base URL，读取方式保持一致。

const library = new AssetLibrary(baseUrl);
await library.search('horse');
await library.describe('creature.horse');
await library.resolve('creature.horse');
