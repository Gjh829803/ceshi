# 人形机器人 · 分类占位

稳定 ID：`robot.humanoid-placeholder` · 版本：`0.1.0` · 状态：`placeholder`。

- 身份、形态：asset.json
- 运动、控制、交互：capabilities.json
- 实际资源及 SHA-256：resources.json
- 来源及未知授权项：provenance.json
- 骨骼、动作、挂点：bindings/
- 完整入口：assemblies/default.json
- 实测范围：validation/latest.json

用根目录的 client/asset-library.mjs 按 ID 读取。浏览器看板只预览资源；运动控制和物理仍由宿主提供。
