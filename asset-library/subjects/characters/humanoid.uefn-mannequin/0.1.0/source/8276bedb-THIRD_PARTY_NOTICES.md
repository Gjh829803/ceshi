## Epic GASP research data

`reference/gasp-samples/` contains 26 downloaded Epic-content sample files from that commit: 22 animation sequences, their common skeleton, and three traversal montages, together with extracted data. `public/assets/gasp-research/` contains 22 experimental GLB conversions and related reports/metadata. The main lab loads 21 sequences; `run-pivot` remains an unused source comparison because it describes forward-to-backward movement rather than a body turn. `/gasp.html` retains the earlier original-sequence comparison viewer. These GLBs derive from Epic animation and skeleton data; see the upstream asset notice linked above.

The gray segmented proxy geometry is generated by this project; Epic's original skinned mannequin mesh and textures have not been exported. See `public/assets/gasp-research/LICENSE-NOTICE.txt`, `reference/gasp-samples/MOVEMENT_EXTENSION.md`, `movement-extension-sources.json` in that same directory, the earlier sample records, and each conversion report for provenance and hashes.

The playable lab's `src/gasp/motion.ts` implements project-authored root-path adaptation and ordinary pose blending. It does not contain or claim to reproduce the Unreal SkewWarp or full PoseSearch engine implementation. Collision filtering during traversal excludes only the selected obstacle from the standing-capsule movement query; this is not full-body collision against that obstacle.

## Quaternius baseline

`public/assets/web-reference/` derives from local Quaternius Universal Animation Library 1 & 2, CC0. Original license files remain under `public/assets/`. Repackaging selects a single animation per file without changing nodes, skins, animation channels, keyframes, or binary data. This fixture is not a GASP animation export. These fixtures and previous model files remain available for historical diagnosis; the current main lab additionally uses the land/surface motions and swimming conversions described below.

## Quaternius swimming retargets

`public/assets/swimming/{swim-idle,swim-forward}.clip.json` retarget the local UAL1 Standard `Swim_Idle_Loop` and `Swim_Fwd_Loop` sequences (CC0). The original source notice is retained in `LICENSE-SOURCE-CC0.txt`, with source/target/output hashes and measurements in `audit.json`. Source: https://quaternius.com/packs/universalanimationlibrary.html.

Modifications: target bind-axis correction, anatomical segment alignment, spine/neck chain resampling, fixed target bone offsets and unit scales, target-scaled pelvis bob. The target is the existing Epic-derived 101-bone skeleton. This swimming conversion is project-authored code in `scripts/retarget-swimming.mjs`, not UE engine code or an Epic swimming export.

## Quaternius land and surface motions

The main lab loads 24 additional CC0-source UAL clips from public/assets/actions: roll; slide entry/loop/exit; carry walk; table pickup; sitting entry/idle/exit; eight climbing clips; seven crawling clips. A 25th converted pickup-ground reference is not runtime-loaded or exported. Original UAL1/2 Standard files supply the first group. The additional climbing/crawling groups derive from CC0-licensed publicly redistributed full UAL files, not the smaller Standard downloads. Author pages: https://quaternius.itch.io/universal-animation-library and https://quaternius.itch.io/universal-animation-library-2 . Exact source URLs, source licenses and SHA-256 inventories are retained in reference/additional-animations and public/assets/actions.

Modifications in scripts/retarget-land-actions.mjs: bind-axis retargeting, fixed target bone offsets/unit scales, in-place root handling, bounded ground-height adjustment for the segmented proxy. Ladder control reuses rock-wall climbing motions; these are not dedicated ladder or symmetric ledge-hanging recordings.

## CMU freestyle motion capture

public/assets/swimming/swim-freestyle.clip.json derives from CMU subject 125, trial 06 (Free Style), using the 24.0–27.5-second portion of Bruce Hahne's MotionBuilder BVH conversion. Primary source and terms: https://mocap.cs.cmu.edu/ ; trial listing: https://mocap.cs.cmu.edu/search.php?subjectnumber=125 . CMU links the conversion from its resources page. The downloaded BVH mirror and unmodified converter README are documented in reference/additional-animations/README.md.

CMU permits use for research and within larger products but prohibits direct resale of the original or converted data. This source is not CC0. Attribution: The data used in this project was obtained from mocap.cs.cmu.edu. The database was created with funding from NSF EIA-0196217.

Modifications in scripts/retarget-freestyle.mjs: crop, resample to 30Hz, target bind-axis correction and segment alignment, fixed bone lengths/unit scales, water-plane origin and a short continuous loop closure. Source/output hashes and measurements are in public/assets/swimming/freestyle-audit.json.

The local exports/action-kit package contains the same mixed-source runtime data (21 GASP, 24 UAL land/surface, 2 UAL swimming, 1 CMU freestyle clips), original notices and a reusable controller module.
