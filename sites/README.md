# Sites

`world-sdk-blueprint/` is a historical architecture publication for the earlier
runtime. Its page and tests have not been migrated to the Three branch. It remains
outside the pnpm `apps/*` workspace and retains its own build tooling.

The current design is documented in [Three SDK architecture](../docs/three-sdk-architecture.md)
and the [production guide](../docs/three-sdk-data-production.md). This documentation
cleanup does not publish or modify the existing Site implementation.
