# UEFN mannequin (Source101 rig)

`model.glb` is the skinned base model for `humanoid.uefn-mannequin`. The catalog
packages it with the full action resources under `presets/humanoid/source`.
Use `createHumanoidWorld` for contextual traversal, swimming, posture and
interaction. `world.assets.load` provides the same subject for ordinary SDK
actor binding; clip playback alone does not activate contextual physics.

Keep the supplied visible body, colors, animation skeleton and actions by default.
Source hashes and conversion details are in `provenance.json`; notices and
licenses accompany the action files.

The default visible skin is now the user-supplied
`UEFN_Mannequin_BlackJoints_LOD1_Medium.fbx` (3,481 vertices / 4,660 triangles),
with embedded white/black-joint color and normal textures. Its 87 source bones
are bound offline to the existing 101-bone animation rig; the full controller
still loads the original 48 actions. Runtime assets are self-contained and do
not read the delivery folder.

Rebuild the visual skin with Blender `scripts/assets/export-uefn-mannequin.py`,
then `node scripts/assets/bind-uefn-mannequin.mjs <converted.glb>`,
`node scripts/assets/register-uefn-mannequin.mjs` and
`python packages/creator-host/scripts/assets/build-humanoid.py`. Use `--check` on the final
command to verify generated bytes. See the measured contact adjustments and
validation in [the replacement record](../../../../docs/reviews/uefn-mannequin-lod1-20260911.md).
