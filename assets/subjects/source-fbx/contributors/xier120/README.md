# xier120 source FBX inventory

This directory contains 19 independently modeled FBX source assets by `xier120`.
The catalog keeps the original relative path, creator-qualified source ID,
repository path, byte length, and SHA-256 hash for every file.

The assets cover animals, ground vehicles, aerial vehicles, and rider/vehicle
compositions. They remain `source-only`: conversion and runtime validation are
required before any asset can be registered as a runnable SDK subject.

Blender working files, backup files, and unvalidated GLB exports are not part of
this source inventory.
