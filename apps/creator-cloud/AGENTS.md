# Creator cloud operations and maintenance

Read [cloud execution](three-eval-README.md). Preserve admission, exact account
routing, immutable source/runtime locks, request recovery and shared review identity.
Load production task instructions from `packages/creator-host/docs/agent/README.md` in
the selected toolkit; do not copy or independently rewrite them.

New capsules must contain the real production dependency closure and source bytes.
Local stage/build/doctor tests do not authorize remote upload, deployment or jobs.
Never start, restart, stop or replace production jobs without the requested scope.
Unknown request results require reconciliation by original identity before retrying.
Use the approved exact account mappings and check current availability separately.
