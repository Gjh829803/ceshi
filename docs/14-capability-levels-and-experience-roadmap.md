# 能力分层与体验路线

## 1. 产品目标

目标不是只生成白膜场景，而是逐步达到 AAA 城市游戏的复杂度，同时增加传统游戏没有的自由度：

> WASD 控制玩家身体，自然语言控制整个世界。

Coding Agent 负责创造世界；World SDK 维护底层规则和唯一世界真相；Runtime World Director 把语言转换成受控的世界变化；World Model 负责让变化始终美观、连续并符合世界状态。

## 2. World Model 原子能力维度

美观是所有等级的质量底线。在此前提下，World Model 分别沿四个独立维度增长：

| 维度 | 0 | 1 | 2 | 3 | 4 |
|---|---|---|---|---|---|
| 场景结构复杂度 | 开阔室外 | 城市街景、多个客体 | 室内、多房间 | 室内外连续、多层空间 | 完整城市与流式世界 |
| 镜头变化速度 | 静止或缓慢观察 | 步行、奔跑 | 载具、追逐、快速旋转 | FPS 甩枪等极快变化 | 同时覆盖全部速度并稳定切换 |
| 世界维持时长 | 1 分钟以内 | 1–10 分钟 | 10–60 分钟 | 小时级 | 跨会话持久 |
| 状态遵循能力 | 保持整体风格 | 保持地形、镜头和大轮廓 | 保持实体身份、数量和动作 | 局部变化不破坏其他区域 | 多视角、跨会话保持同一世界 |

这四个维度必须分别评测。例如 FPS 镜头可以先在简单竞技场验证，小时级一致性可以先在慢速场景验证，不能一次同时提高全部难度。

## 3. World SDK 原子能力维度

自由性是 SDK 的设计底线。在此前提下，SDK 沿四个独立维度增长：

| 维度 | 0 | 1 | 2 | 3 | 4 |
|---|---|---|---|---|---|
| 主体与镜头 | 第三人称人形 | 第一/第三人称人形 | 动物、汽车等单体主体 | 骑乘、组合载具等复合主体 | 飞行、特殊镜头、多主体与控制权切换 |
| 世界复杂度 | 开阔室外 | 更多标志物与客体 | 城市街区和道路 | 室内、多房间、多层 | 室内外连续、完整城市与流式加载 |
| LLM 可控制能力 | 观察世界 | 修改外观和实体参数 | 位置、尺度、出现/消失、物理参数 | 动作、寻路、行为和 NPC AI | 多步任务、关系、规则与世界级编排 |
| 游戏性复杂度 | 移动与碰撞 | Trigger 和基础交互 | 道具、车辆、任务与目标 | 战斗、潜行、阵营和动态事件 | 联机、经济、长期状态与社会系统 |

Coding Agent 的创作和验证能力是横向底座：每增加一级世界能力，都必须能被 Agent 定义、检查、重建和测试。LLM 只提出目标，确定性 SDK 仍负责逐帧执行。

## 4. 组合能力分层

原子维度用于评测；组合等级用于定义能够交付的完整产品能力。

### 4.1 World Model 组合等级

| 等级 | 场景 | 镜头 | 时长 | 状态遵循 |
|---|---|---|---|---|
| W1 开阔世界 | 室外、少量主体 | 步行/奔跑 | 数分钟 | 地形、主体、镜头稳定 |
| W2 密集空间 | 城市街景、多客体、基础室内 | 奔跑/载具 | 10–30 分钟 | 多实体身份和局部变化稳定 |
| W3 AAA 动作世界 | 室内外、多层、大量角色 | 载具/战斗/FPS | 约一小时 | 快速运动下仍服从实体与动作状态 |
| W4 持久世界 | 完整城市和流式区域 | 全速度 | 小时级到跨会话 | 多视角共享长期身份和外观记忆 |

白膜预览是 SDK 的开发与降级显示方式，不属于 World Model 等级。World Model 的可交付组合能力从 W1 开始。

### 4.2 World SDK 组合等级

| 等级 | 主体与镜头 | 世界 | LLM 控制 | 游戏性 |
|---|---|---|---|---|
| S0 可玩白膜 | 第三人称人形 | 室外高度场 | 只观察 | 移动与碰撞 |
| S1 可导演世界 | 人形与骑乘等首批主体 | 开阔世界 | 外观、参数、Transform 和基础物理 | 基础交互 |
| S2 活着的空间 | 人形、车辆、复合主体 | 城市与基础室内 | NPC 动作、寻路和行为 | 任务、载具和角色交互 |
| S3 系统化游戏 | 多主体和专用镜头 | 连续多层城区 | 多步事件与任务编排 | 战斗、潜行、交通和阵营 |
| S4 持久世界 | 多玩家、多控制源 | 完整流式城市 | 长期关系、规则和多 Director 协作 | 联机、经济与持久社会系统 |

## 5. 分阶段体验

### P0：湖畔白膜远行 — S0 内部基线

用户输入一句话或图片，几分钟后进入一个可玩的湖畔白膜世界。玩家沿湖奔跑、翻过山坡、走向远处高塔，并能检查每块地形和标志物从何而来。这个阶段用于验证 SDK，不算 World Model 产品交付。

### P1：月球幽灵骑士 — S1 + W1

玩家骑马穿过夕阳草原，说：“把这里变成月球，把我的马变成幽灵马。”世界在骑乘过程中连续变形；玩家再说“降低重力”，随后骑着幽灵马跃过新出现的陨石坑。

### P2：霓虹雨夜送货 — S2 + W2

玩家骑摩托穿过拥挤的雨夜街区，把非法记忆芯片送进地下酒吧。被无人机追赶时，玩家说“让街区停电，只留下通往酒吧的招牌”，整条街随即成为一条由语言创造的逃生路线。

### P3：城堡前的约会 — S2 + W2

玩家与一个授权数字角色在主题乐园约会，一起散步、聊天和乘坐设施。玩家说“去城堡前和我跳舞，再让周围的人鼓掌”，角色会理解、寻路、面对玩家并完成双人舞，随后雪花和烟花覆盖整个乐园。

### P4：空中列车劫案 — S3 + W3

玩家说：“我想在不伤害平民的情况下，夺走空中列车里的公司数据库。”世界把这句话变成一场可以亲自潜入、谈判、战斗和逃亡的任务；行动中玩家还能临时要求停电、改变天气或让接应车辆更换地点。

### P5：凌晨四点的第九区 — S3 + W3

玩家从高层公寓出发，无加载地进入街道、地铁、酒吧、地下设施和公司大楼。帮派、警察、交通和任务持续运行；玩家可以说“让码头帮派今晚叛乱”或“把废弃大楼变成我的基地”，城市会在保持因果关系的情况下真正改变。

这是第一款达到 AAA 城区复杂度的垂直切片。

### P6：可重写的持久世界 — S4 + W4

玩家在已经生活数十小时的赛博朋克城市里说：“从下一个街区开始，把城市变成长安，但保留所有人的身份和正在发生的任务。”建筑、交通和能力体系逐步转换，而朋友、敌人、关系和历史继续存在；其他玩家进入后看到的是同一个被共同改写的世界。

## 6. 路线判断标准

每个阶段只有在下面三件事同时成立时才算交付：

1. 玩家可以直接操控，而不是观看生成视频。
2. 玩家可以用自然语言改变正在运行的世界。
3. 改变后的逻辑状态与最终画面保持一致。

路线的增长顺序是：

```text
能进入世界
→ 能用语言改变世界
→ 世界里有可控制的角色与事件
→ 世界具备完整游戏系统
→ 达到 AAA 城区复杂度
→ 成为可长期存在、持续重写的世界
```
