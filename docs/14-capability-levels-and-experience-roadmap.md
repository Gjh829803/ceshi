# 能力分层与体验路线

## 1. 产品目标

目标不是只生成白膜场景，而是逐步达到 AAA 城市游戏的复杂度，同时增加传统游戏没有的自由度：

> WASD 控制玩家身体，自然语言控制整个世界。

Coding Agent 负责创造世界；World SDK 维护底层规则和唯一世界真相；Runtime World Director 把语言转换成受控的世界变化；World Model 负责让变化始终美观、连续并符合世界状态。

## 2. World Model 能力分层

| 等级 | 能力边界 |
|---|---|
| W0 白膜预览 | 没有生成式渲染，直接显示确定性白膜。 |
| W1 开阔世界 | 稳定表现室外开阔空间、少量主体和步行/奔跑镜头，维持数分钟一致性。 |
| W2 密集空间 | 稳定表现城市街景、多客体、基础室内和较快移动，维持 10–30 分钟身份与空间一致性。 |
| W3 AAA 动作世界 | 支持室内外、多层空间、大量角色、载具、战斗和 FPS 级快速镜头，维持约一小时连续体验。 |
| W4 持久世界 | 支持完整城市、小时级运行、跨会话身份与外观记忆，以及多个玩家视角下的同一世界。 |

所有等级都必须服从 SDK 的位置、数量、动作、遮挡和相机条件；等级提升的本质，是同时提高场景复杂度、镜头速度和一致性时长。

## 3. World SDK 能力分层

| 等级 | 能力边界 |
|---|---|
| S0 可玩白膜 | 第三人称人形可以在室外地形中稳定移动，世界可由 Agent 创建和验证。 |
| S1 可导演世界 | 支持更多主体和镜头，Director 可以受控改变环境、实体外观、参数和基础物理规则。 |
| S2 活着的空间 | 城市、室内、车辆和 NPC 能共同运行；玩家可以用语言安排寻路、动作、交互和简单事件。 |
| S3 系统化游戏 | 世界具有任务、战斗、潜行、交通、阵营和动态事件，Director 可以编排可玩的多步剧情。 |
| S4 持久世界 | 世界可以流式扩展、长期保存、联机运行，并处理多个玩家和多个 Director 之间的权限与冲突。 |

SDK 等级越高，语言可以改变的就越多；但 LLM 始终只提出目标，确定性系统负责逐帧执行。

## 4. 分阶段体验

### P0：湖畔白膜远行 — S0 + W0

用户输入一句话或图片，几分钟后进入一个可玩的湖畔世界。玩家沿湖奔跑、翻过山坡、走向远处高塔，并能检查每块地形和标志物从何而来。

### P1：月球幽灵骑士 — S1 + W1

玩家骑马穿过夕阳草原，说：“把这里变成月球，把我的马变成幽灵马。”世界在骑乘过程中连续变形；玩家再说“降低重力”，随后骑着幽灵马跃过新出现的陨石坑。

### P2：霓虹雨夜送货 — S2 + W2

玩家骑摩托穿过拥挤的雨夜街区，把非法记忆芯片送进地下酒吧。被无人机追赶时，玩家说“让街区停电，只留下通往酒吧的招牌”，整条街随即成为一条由语言创造的逃生路线。

### P3：城堡前的约会 — S2 + W2

玩家与一个授权数字角色在主题乐园约会，一起散步、聊天和乘坐设施。玩家说“去城堡前和我跳舞，再让周围的人鼓掌”，角色会理解、寻路、面对玩家并完成双人舞，随后雪花和烟花覆盖整个乐园。

### P4：空中列车劫案 — S3 + W3

玩家说：“我想在不伤害平民的情况下，夺走空中列车里的公司数据库。”世界把这句话变成一场可以亲自潜入、谈判、战斗和逃亡的任务；行动中玩家还能临时要求停电、改变天气或让接应车辆更换地点。

### P5：凌晨四点的第九区 — S3 + W3

玩家从高层公寓出发，无加载地进入街道、地铁、酒吧、地下设施和公司大楼。帮派、警察、交通和任务持续运行；玩家可以说“让码头帮派今晚叛乱”或“把废弃大楼变成我的基地”，城市会在保持因果关系的情况下真正改变。

这是第一款达到 AAA 城区复杂度的垂直切片。

### P6：可重写的持久世界 — S4 + W4

玩家在已经生活数十小时的赛博朋克城市里说：“从下一个街区开始，把城市变成长安，但保留所有人的身份和正在发生的任务。”建筑、交通和能力体系逐步转换，而朋友、敌人、关系和历史继续存在；其他玩家进入后看到的是同一个被共同改写的世界。

## 5. 路线判断标准

每个阶段只有在下面三件事同时成立时才算交付：

1. 玩家可以直接操控，而不是观看生成视频。
2. 玩家可以用自然语言改变正在运行的世界。
3. 改变后的逻辑状态与最终画面保持一致。

路线的增长顺序是：

```text
能进入世界
→ 能用语言改变世界
→ 世界里有可控制的角色与事件
→ 世界具备完整游戏系统
→ 达到 AAA 城区复杂度
→ 成为可长期存在、持续重写的世界
```
