# Documentation

- Numbered Markdown files describe the current product, architecture, and workflows.
- [`24-subject-pack-delivery-and-intake.md`](24-subject-pack-delivery-and-intake.md)
  is the practical handoff contract for adding reusable static or rigged Subject
  Packs to Registry, Runtime, Studio, and the Agent Catalog.
- `decisions/` contains project-wide architecture decision records.
- `reviews/` contains source-backed reviews and completion evidence.
- `assets/` contains documentation-only media.

Superpowers-produced specifications, plans, and reusable project guidance live under
`superpowers/`. The root `.superpowers/` directory is reserved for tool workflow state,
not durable documentation.
