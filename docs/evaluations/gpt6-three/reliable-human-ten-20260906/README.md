## 宿主可靠性

Host 动态发现就绪 Ray head；未知提交先按精确 requestId 对账。仅重复确认 404 时重放同一份持久化请求和同一幂等键，不生成新的 requestId。
执行终止后立即释放模型并发额度；产物缺失重取同一任务的 S3/FSx 固定文件，校验传输哈希。未知执行与未确认取消继续保留额度，不能当作已停止。
宿主 supervisor 保存运行锁路径、案例清单、账号策略与任务身份，并持有单一进程租约。重启后继续对账和取产物，不重新生成已存在任务。
上述改动没有进入正常 Agent 创作上下文；本轮没有追加个案修复提示、手工修改生成世界或引入预算催促文案。
