版本 2，2026-09-05。制定时本轮 Three SDK v2 模型任务尚未提交，未查看本轮模型产物。
本文件保留并引用[版本1参考图/路线标准](acceptance-plan.md)，不覆盖其原文或原SHA。

变更依据：用户已明确方向键控制镜头，并授权补齐运动、状态/环境和几何扩展后并发生成五例。

- 输入标准改为 WASD 移动、四方向键转镜头，Shift持续跑、Space新按下一次跳。方向键单独操作不得产生人物水平位移；旧版表格将方向键列为移动键的内容由本条替代。
- 普通跳持续使用已验证jump语义，落地按真实速度回idle/walk/run，不自动硬落地或锁住移动。遮挡离墙恢复平滑；新障碍需要立即安全纠正时如实记录。
- R键和工具reset均需恢复同一公开世界：初始相机、人物、参数、机关、几何及任务状态，不能只恢复私有物理层。暂停、加载、缓存样本不得计作主动游玩时长。
- 本轮恰好五个three-sdk案例，使用同一冻结SDK/工具/浏览器闭包、gpt-6-astra/xhigh，并发上限5；实际开始时间、排队时间、模型时长分别记录。没有额外raw五例，因此本轮效果不能用作同预算raw-vs-sdk因果结论。
- 自由Three几何、完整主体和参考相机政策保持。扩展允许真实运动意图、声明的状态/环境参数和经过校验的Mesh几何替换；不因注册了一个运动名称就自动宣称具备导航、攀爬、飞行或骑乘行为。
- 参考图SHA、原始需求、五个场景各自的关键路线、首帧/完整主体/真实支撑标准沿用v1。特别是森林必须实际登上塔的平台，梯田有真实层级，宫殿桥与高差真实相连，九尾狐整体随动，海岸包含高低岸与侧向探索。
- 每例至少180秒主动游玩及主观质量独立审阅。技术交付、首帧、主体、道路/支撑、操作/生命周期、探索内容分别报告passed/failed/not-verified；作者自报targets和passed不代替独立结论。
- 失败原始输出和错误记录保留。可玩的有缺陷案例可进评测页并标明问题；不得人工修世界源码后称为原始模型结果。
