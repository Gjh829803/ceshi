# Historical evaluation evidence

These directories retain source-bound evaluation policies, case reviews, runtime
locks, source patches and deployment records. Their original inputs and runtime
bytes must not be reinterpreted as a release of the current branch.

- `gpt6-three/`: Three experiments, acceptance policies and campaign evidence.
- `gpt6-creator/`: earlier Creator/Native experiments retained as historical comparisons.

Read each record's date, source identity and scope. These are not instructions
to restart or retry a campaign. Current entry points and capability boundaries
are in the [production guide](../three-sdk-data-production.md).
