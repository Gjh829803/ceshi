# Unique Asset Library Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development or superpowers:executing-plans to implement task-by-task. Independent audit domains may run in parallel with bounded ownership.

**Goal:** Remove this branch's legacy asset source and make all consumers use asset-library.

**Architecture:** Subject JSON and dedicated library bindings are the only authoring source. Generate content-addressed Creator catalogs and direct-URL Playground definitions from those records. Host source access selects one local root or HTTP origin and preserves hashes; finished game bundles are immutable snapshots.

**Tech Stack:** Node ESM, TypeScript, JSON Schema, Vite, Vitest, Playwright, existing Three SDK.

**Spec:** docs/superpowers/plans/2026-09-17-unique-asset-library-spec.md

- Work only on codex/subject-library-demo; preserve the existing demo and user-owned changes.
