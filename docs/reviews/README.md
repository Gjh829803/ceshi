# Three review and verification records

The current review rules are [the review protocol](full-dimension-review-protocol.md)
and [the runtime checklist](runtime-deep-review-checklist.md).

Dated files record specific source states, experiments and findings. Read their
SHA, scope and verification limits before reuse. Historical findings require a
current-source recheck; historical passes do not verify a later HEAD or deployment.
These records do not authorize a campaign, retry or provider submission.
