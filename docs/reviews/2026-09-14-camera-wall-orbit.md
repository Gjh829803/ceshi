# 贴墙环绕构图修复验证

用户在沙海古城中贴墙环绕时，人物横向离开画面，观感像两个相机交替接管。
调查确认是同一控制器内部的机位与构图不同步：碰撞修正只替换眼位，保留了原始
轨道朝向；不同臂长的固定帧直接插值也未维持支点的画面方位。

## 修复范围

实现与维护约束归[相机架构](../three-sdk-architecture.md#相机控制权与交接)。
共享 SDK 增加纯构图计算，策略保存不可变轨道基底、相对构图和参考方向。
安全机位及显示插值使用同一数学映射；输入准备预测相同安全构图，事务恢复后
仍由原固定提交拥有恢复状态。第一人称继续遵循输入视线。

独立复核发现并修正了输入仍沿用名义朝向、极点重复校正不幂等、角度分支切口
和显示端点跳转。最终复核无阻塞项。未修改场景、资产预设、车辆物理、碰撞
安全求解或 CameraDocument schema；未增加生产步骤、门禁或相机写入者。

## 验证

- 新回归先在旧行为上失败：墙面阻止连续环绕、不同臂长的显示插值、受约束
  镜头的输入方向。后续补充极点数值扰动、幂等、反向视线及显示端点回归。
- 最终 15 个文件、239 项测试通过，覆盖 SDK 相机、公开主体契约、人物、骑乘、
  生命周期、Episode，以及 Creator 真实浏览器捕获和载具消费者。
- 类型检查、相机目录 lint、测试清单通过；清单仍为 137 文件，不新增测试入口。
- 同一场景、同一起点 `[-4.05, 0, 61]`、同一水平环绕输入，960×960 画面采样
  180 帧。旧版人物根节点横向出框 4 帧，最大绝对 NDC X 为 1.248095；最终版
  出框 0 帧，最大绝对 NDC X 小于 1e-12，浏览器错误为空。
- 骑马对照各 360 步：前后停顿均为 0，最大名义/实际机位偏差均为 0，最大
  镜头步长均为 0.115936 米，主体位移均为 36.973667 米。
- Creator 完成原有 17 步真实输入与录像，技术状态 passed，页面和运行时错误
  为空。录像 19.878 秒，87 帧，960×540；语义验收仍为 unreviewed。

根节点方位的数值检查不代表整个人物始终完整入镜。狭窄区域避墙仍可能迫使镜头
贴近角色；本次未实现近距离人物淡出。极点与精确反向视线的取舍见权威架构，
上述局部回归不代表任意场景或所有视角都已完成玩家手感验收。
