## 实现与职责

- SDK 清理无消费者的旧 heading 状态声明，修正当前人物眼位和视角切换说明。
  历史检查表保留原记录，明确指向当前架构和完成记录。
- 自动规则保持已有回退语义，同时返回候选 viewId、原始错误码、字段路径和原因；
  默认视角不可用时也说明实际保留的视角。诊断没有增加生产步骤或门禁。
- `orientation.recenter.yawTarget` 支持主体朝向、水平运动方向和指定世界朝向。
  默认值保留主体朝向；运动方向在没有有效水平速度时保持环绕，倒车时跟随倒车方向。
  SDK 适配器提供实际速度，策略负责坐标转换，继续使用原等待时间和半衰期。
- 字段说明由 SDK schema 维护，生成到 Creator 发现；Playground 复用说明和分支定义，
  提供布尔及回正目标选择控件，组合参数显示有效值和混合来源。
- 相机性能诊断默认关闭，按需记录输入、固定步求解、显示修正和探针调用成本，
  每阶段最多保留 240 次记录。读取不推进模拟，计时不可用不停止 World。
  UI 复用既有渲染回调，实时诊断与稳定参数表单分别刷新，卸载时解除订阅。
- 维护脚本集中在 `apps/sdk-playground/scripts/camera-quality/`：路线、比较、编辑验收
  各自负责一件事。沿用公开 SDK/Episode 接口，无另一个物理世界或相机控制器。

本轮未修改团队标定 JSON、碰撞求解算法、车辆操控或生产调度。

这些数据承诺全场景提速。对照输入和采样身份固定，维护脚本拒绝不同路线或不同
版本脚本的基线。首轮交付前最后的前端刷新和帮助文档调整未改变该次 SDK 运行时字节；
下述复审修复会产生新的运行时身份，不能以首轮录制冒充修复后的录制。
