# 独立主体人称切换验收

在通用 `setCameraFollow({view})` 中配置主体本地眼位、默认第一/第三人称及
快捷键开关；复用现有 T 键绑定，可重绑。`world.setCameraPerspective()` 支持
程序切换，不改变配置的重置默认值。用法见
[独立非人主体](../../packages/three-world/README.md#independently-controlled-nonhuman-subject)。

## 边界

- 无需新世界入口或人物占位。眼位由作者按模型给出，使用主体世界变换及语义前向；
  第一人称使用稳定地平线，不推断任意动物的颈部骨架或步态。
- 相机仍由既有 Rig 与固定时钟驱动，复用 camera-collision 求解。
  主视角在展示事务中暂时排除主体绘制层，完整物体视图与逻辑可见性保留。
  正常和异常退出均恢复绘制层。
- 快捷键尊重开关、UI 焦点、暂停和单次输入边沿。程序切换独立于快捷键权限。
  第三人称距离与作者近裁剪面保留，启动前临时切换不污染配置默认。
- Episode 默认继承源世界，`start.cameraPerspective` 可覆盖单个片段，优先于
  Training 旧数字模式。原有未配置视角的世界保持第三人称行为。
- Agent 按需文档、公共契约、狐狸示例及 Episode 起点 schema 同步；无新增生产阶段。
