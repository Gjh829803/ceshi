# Training 默认视角与快捷键配置验收

复用现有 `TrainingProfile.view` 接入默认第一/第三人称及快捷键开关，配置示例见
[SDK 指导](../../packages/three-world/README.md#default-view-and-keyboard-switching)。
缺省保持第三人称、快捷键关闭；开启后默认 T，可通过既有按键表重绑。
快捷键只切换第一/第三人称，程序仍可选择已有三种模式。
车辆转弯倾斜沿用控制器和第一人称相机的现有行为，不增加开关或镜头循环。

## 责任与生命周期

- Profile 保存默认值，snapshot 返回有效配置。重置/换图恢复默认跟随视角，
  已交给作者的相机仍保留作者控制权。更新快捷键权限不会改变当前视角。
- Episode 起点省略模式时继承默认，显式片段覆盖不改写默认。
- 单次按键沿既有固定输入路径消费；暂停、UI 焦点、长按和多 tick 不重复切换。
  Playground 使用 SDK 按键路径；菜单仍可单独选择越肩模式。
- 人物三视图通过已有同步展示事务临时恢复完整几何，随后恢复第一人称裁切，
  再重绘主画面。正常及异常退出均恢复状态，不切模式或推进模拟。
- Creator 按需指导、当前工作区源码定义和命令 schema 同步，无新增工具阶段或门禁。
