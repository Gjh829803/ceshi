# Creator 主体选择与入口文档集成验收

## 设计边界

`createWorld` 是通用入口；`createHumanoidWorld` 组合完整人物套件，内部复用前者，
返回相同世界类型。当前不增加 `createNonHumanWorld`。主体外形、运动能力与
骑乘关系分别描述，所有路线复用既有 SDK 调度和 Creator / Episode 交付协议。
详细边界见 [架构](../three-sdk-architecture.md#入口与封装边界)。

环境、schema、示例和 Episode 指导同步按所需主体选择能力；非人主体不额外
添加人物。增加独立狐狸示例，不增加模型调用阶段、必填主体字段或交付门槛。

## 与新增相机视角的集成

集成开发分支 `d85d087058d96ac14c564516726c9a2b1f3b5090` 后，第一人称
临时裁切头颈 geometry 会触发旧人物诊断误报。Host 现在在第一人称跟随模式
暂缓 geometry 身份判断，并明确报告 `partial`；根、网格、骨架和骨骼身份
继续检查。空索引网格豁免可见性检查，其余身体网格仍须可渲染。
返回普通视角后恢复原 geometry 检查；首次即为第一人称时不把临时 geometry
当作正常基线。没有改动 SDK 相机、人物或模拟行为。

- 完整 `pnpm test` 初跑：241 项 contract 通过；resource-heavy 541 项通过，

  需要完整浏览器及正常 HTTP 文档；headless shell 或 `about:blank` 均报
  `WrongDocumentError`。测试改用完整 Chromium 和本地拦截提供的 HTTP 页面，
  原有真实锁定断言保留。修正后定向重跑输入 9 项、浏览器配置 2 项全部通过；
  未再次运行整套聚合命令。
- 人物连续性单元与真实 SDK 浏览器回归共 37 项通过，包括实际第一人称裁切、
  原 geometry 恢复、重复捕获、隐藏身体、骑乘和附件身份。

  9.35 秒。狐狸交付包经独立 Episode source 适配，完成 48 帧、24 fps、
