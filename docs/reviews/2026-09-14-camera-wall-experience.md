# 靠墙环绕体验修复

起点为相机分支 `9aec6b0a`。用户的连续录屏显示远景、鞋底和身体特写反复切换。
此前只证明人物根节点横向未出框，不能证明镜头运动连续、构图可玩或近距离遮挡合理。
本轮以连续画面和同一场景的逐帧轨迹为验收依据；早期报告的技术结果不等于体验验收。

## 根因与处理

- preserve-opening 将环绕支点固定在主体原点，已声明的人物身体锚点被标为 inactive。
  现在两种第三人称构图都使用同一锚点与偏移，保留开场时从原机位、朝向和 FOV
  重新分解轨道。通用未声明锚点的文档保留 origin 默认，明确的人物预设使用身体锚点。
- preserve-framing 绕过实心镜头臂遮挡，直到镜头自身接触才突然收缩。SDK 移除此绕过，
  保留构图只省略额外主体可见性射线，镜头臂、眼位球体和扫掠路径始终参与安全计算。
- 单纯缩短臂长无法解决墙角转向时的突变。收缩使用安全路径与有限内收候选；恢复
  受阻时沿已有安全臂内收以脱离立柱，不能永久停留在一个安全但无法恢复的旧眼位。
- 墙角脱困还存在几乎纯角向的追赶跳跃：一次连续录像中臂长仅变化约 0.008 米，
  两帧眼位却移动 1.306 米。碰撞历史中的角向追赶复用有限修正速度，不叠加半衰期；
  实际机位追上目标后才释放恢复状态。无碰撞历史的自由旋转保持原响应。
- 近距离人物显示由共享 `subjectFade` 配置控制，只在展示事务内淡出跟随主体与骑手，
  恢复共享材质和可见性，保留对象着色的 shader hooks。对象三视图和第一人称不使用它。
- 锚点编辑、撤销、主体搬迁、上下坐骑、同文档重装和重置共享开场引用迁移；速度拉远
  不重复计入意图，世界空间偏移不会随主体朝向旋转。非活动视角明确修改锚点时重建
  该视角基线，其他编辑保留轨道缓存。

默认第三人称收缩半衰期 0.08 秒；受限路径的收缩及角向追赶上限 12 米/秒，
径向恢复上限 8 米/秒。近主体淡出
从 1 米开始、0.45 米结束。第一人称保留立即修正与无限恢复速度。参数由 SDK schema、
元数据和生成的发现文档维护，Playground 通用控件直接消费，没有场景专用覆盖或新生产步骤。
权威扩展规则见[相机控制权与交接](../three-sdk-architecture.md#相机控制权与交接)。

## 审查中拦截的回归

- 单看硬终点可见性会让镜头穿过途中的静态墙，修正为保留可达眼位并报告遮挡。
- 旧眼真实穿透时，安全脱离不应依赖目标镜头臂是否先被阻挡；目的眼位仍独立验证。
- 开放车厢的柱子可导致恢复扫掠渐近停滞，补几何柱体和真实车辆两层持续恢复回归。
- 公共内核拒绝零回缩速度，避免合法输入产生永久零进度；失败保持事务回滚。

## 验证边界

开场机位保留不代表完整移动轨迹逐字节不变：明确的身体锚点现在参与环绕，近墙会
采用安全收缩与人物淡出。旧眼被动态障碍真实占据时，安全脱离可超过平滑速度限制。
当目标轨迹长期快于配置的修正速度时，碰撞后的追赶可能延迟；该速度可调整，
不对无碰撞的自由轨道施加新限制。复杂几何下安全优先，遮挡反馈不证明存在可见路线，也不承诺所有场景永不遮挡。
生产 case 的技术验收与人工玩法、视觉验收分别记录。

## 最终验证

- 25 个受影响测试文件合计 514 项通过；覆盖配置发现与编译、编辑/撤销、控制器、
  物理查询、开放车厢/实心面板、显示事务、输入、Creator 捕获与 Episode 消费。
  角向修复后重新执行内核/物理/车辆/约束 198 项，以及控制器/显示/真实 World 91 项。
- SDK 与 Playground 类型检查、lint、测试清单、包边界、文档相对文件链接及 diff 检查通过。
  schema 生成产物由生成器更新，真实 Creator 发现与 JSON 配置编译测试通过。
- 原沙海场景不改源码，固定起点 `[-4.05, 0, 61]`，按 60 Hz 执行、30 FPS 捕获
  420 帧（14 秒）：顺时针、逆时针各 6 秒，随后同时转向与抬头 2 秒。
  相邻捕获帧最大眼位位移 **0.400000 米**，大于 0.5 米的跳跃 **0 次**，浏览器错误 **0**。
  中间版本相同操作仍有 1.306/1.331 米角向跳跃，未更新用户预览；最终已消除。
  查看连续帧与接触段画面，鞋底支点消失，近身淡出与恢复按配置生效。
- 开场 camera-to-world 矩阵最大差 `8.88e-16`，投影矩阵差 **0**；首帧截图检查通过。
  骑马前后各 360 步，主体位移同为 **36.973667 米**、镜头停顿 **0**；最大步长
  从 0.115936 到 0.116021 米，未产生碰撞修正。
- 最终 Creator 17 步用例完成上马、行进、切换视角、下马和重置，录制 18.737 秒、
  93 帧、960×540；技术检查通过，录制就绪问题为空。语义状态仍为 `unreviewed`。
- 独立审查确认最终安全路径、实际眼位状态提交与 phase 释放无剩余阻塞项。
