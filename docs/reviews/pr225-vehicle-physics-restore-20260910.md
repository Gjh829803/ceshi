- 轮胎、悬挂压缩限位、动力链、车身姿态回写使用 PR 的实现，仍位于车类目录。
- 车类、水面船类、水里类的专用刚体受力代码从 PR 提取并按现有大类分开；划桨推进、转向及参与接触计算的桨位和握点配套恢复。
