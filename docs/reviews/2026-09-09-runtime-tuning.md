# SDK 内部调参与 Playground 基线

## 结果与边界

开发者调参归入 [`packages/three-world/src/config`](../../packages/three-world/src/config/README.md)，
按控制、相机、动作、输入、物理和展示效果分文件维护。Playground、运行时和 Creator
指导共用相关定义。仓库根目录 `config/` 继续承载 Host 策略、账号与部署配置。

以修改前 Playground 的实际行为为基线：保留人物控制基准 `3.1 / 14 / 5 / 8`
及原有换算关系，人物相机 `58° / 7 / 0.2 m`，载具相机 `55° / 8 / 0.25 m`。
SDK 构造时立即安装这些人物控制值，不再等第一次 `applyProfile()` 才生效。
这里的控制基准不是最终速度；没有为了让字段数值更直观而改动既有手感。

第一人称载具倾斜使用内部 `CAMERA_EFFECTS.vehicleTurnLean`：默认开启、强度 1，
保持原有画面。开关只调整既有视线轴上的相机横滚，不改变载具运动、眼位或视线。
它不进入公共 profile 或 Agent 参数；更改后重建运行时生效。

`exportProfile()` 保留可重放配置；`inspectConfiguration()` 额外返回当前主体实际适用的
控制值、相机配置及控制者。配置观察不推进时间，返回值与运行状态隔离。
发现工具按控制器家族展示有效字段，完整存储形式仍可包含非当前家族使用的字段。
删除 Playground 旧配置迁移和旧模块入口，没有增加生产校验阶段。
