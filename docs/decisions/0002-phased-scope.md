# ADR-0002：第一、二期范围

- 状态：已接受
- 阶段：方案设计

> 实施注记（2026-08-15）：第一期已有可运行 Alpha，但仍处于收敛和验收阶段；第二期尚未开始。World Model Integration 与 Runtime World Director 作为独立后续工作流规划，不强行归入同一个“第三期”。

## 第一期

只实现：

1. 可绑定骨骼和少量动作的第三人称人形主体。
2. 面向室外开放场景的自由地形与标志物搭建。

第一期的自由世界搭建建立在可追踪的 `WorldFeature` 扩展协议上，不要求 SDK 预置所有自然地貌和标志物类型。

## 第二期

扩展：

1. 更多主体类型。
2. 更多主体动作。
3. 室内空间搭建。

## 后续

NPC、寻路、完整玩法、实时世界模型接入以及其他产品能力不纳入当前两期的确定范围。实时世界模型可以现在开始契约与离线导出协作；Runtime World Director 已完成方案设计，但两者都不代表已有实现。

## 原因

第一期需要先证明两个基础能力：主体能否稳定被玩家控制，以及 Coding Agent 能否在受约束、可追踪的框架内自由创造室外白膜世界。其他能力只有在这两个底座成立后才有可靠扩展基础。
