# 海滨小镇

基于 reference.png 的简化白模世界。主要地标：喷泉广场、港口、咖啡馆、上坡旧街和灯塔。

WASD 步行/驾驶，Shift 跑步，F 上下摩托，Space 跳跃/制动，T 切换视角，鼠标拖动环视。
UI 使用独立状态 Schema、组件 catalog、JSON 布局/显隐绑定与 React 组件。世界运行端只输出干净白模画面；播放器叠加 UI。

海面和船只为背景轮廓，海滨围栏限定可探索区域，不提供游泳。城市步道与上下街区相连，可自由探索；多条往返路线估计支持约 5 分钟探索，不等同于已逐路录制 5 分钟。场景没有额外任务或收集要求。

creator-result.json 与录屏交付产物保存在本地验收目录，不进入公共源码。

## 本地直接试玩

在本目录运行 `pnpm dev`，打开 <http://127.0.0.1:53901/>。
默认直接展示同一套 React UI，没有视频编码或 WebSocket 流传输。
`?ui=off` 关闭本地 UI，`?ui=on` 显式开启。WASD、鼠标和组件操作直接作用于当前世界。

流式调试仍从仓库根目录运行 `pnpm dev:stream`，使用 53900 的公共播放器。
