# Three examples

`three-creator/` contains examples for the current SDK. Read the
[SDK guide](../packages/three-world/README.md), or use Creator's
`creator_get_examples` for runnable API examples.

Earlier Canonical, Native and Block world demonstrations and their example
goldens were retired with those implementations. Shared source assets and
historical production evidence remain separate from these demonstrations.

`worlds/` is the [public streaming demo library](worlds/README.md), loaded by
`pnpm dev:stream`. Only worlds using the current streaming UI contract belong there.
