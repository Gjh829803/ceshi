# Examples

`three-creator/` contains Three Creator examples. Start with the current
[SDK guide](../packages/three-world/README.md) and the Creator
`creator_get_examples` tool for runnable API examples.

Other directories retain earlier authoring, terrain, traversal, asset-intake and
capture fixtures. Their files and evidence remain unchanged until the corresponding
code is evaluated for removal. They are not the current Three quickstart or an
additional authoring format that new scenes must adopt.

See [current architecture](../docs/three-sdk-architecture.md).
