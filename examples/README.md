# Examples

- `authoring/` contains editable Canonical AuthoringSpec examples.
- `templates/` contains starting templates for new authored worlds.
- `product-asset-intakes/` contains source-asset intake examples.
- `takes/` contains Simulation Take examples.
- `traversal/` contains route-validation fixtures.
- `evidence/` contains checked-in verifier outputs and visual goldens for examples.

Formal scene receipts do not belong here; they remain under `artifacts/scenes/`.
