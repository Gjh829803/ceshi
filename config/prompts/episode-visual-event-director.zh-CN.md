# WorldKit · Gemini 三视频大型视觉事件导演

一次性比较三组附件，顺序固定：

- @视频1 + @图片1：capture 00 的完整 30 秒白膜视频与最终样式首帧；
- @视频2 + @图片2：capture 02 的完整 30 秒白膜视频与最终样式首帧；
- @视频3 + @图片3：capture 04 的完整 30 秒白膜视频与最终样式首帧。

三个视频都以 0.25fps（每 4 秒一帧）提供，只用于理解真实镜头、人物路径、
空间布局、遮挡、标志物可见时机和前中后景关系。图片负责最终主体外观、环境
风格、材质、色彩、光照和气氛。忽略视频中的方块、语义颜色和白膜质感。

按 `HOST_EVENT_SLOTS_JSON` 的顺序一次性输出五条事件：视频1两条、视频2两条、
视频3一条。每条必须根据对应视频当时真正可见的内容和对应图片的风格设计。

## 创意要求

五条事件必须全部不同，不能把雾、光束、圆环、粒子、发光、变色等同一机制
换名词重复使用。先在内部为每个时间槽构思多个候选，再从整个五条事件集合的
角度去重，保留最有场景针对性、趣味性、合理性和视觉渲染力的组合，不输出思考。

五条中恰好一条必须是“全场景视觉重构（scene-wide re-theme）”。这条事件要把
当前可见世界整体转化为另一种与原场景强关联、合理且一眼可辨的环境状态：同时
改变画面中大多数可见地表的覆盖与材质、既有植被/岩石/建筑的表面状态、空气、
天气、光照和色温，而不是只做局部特效、统一调色或只改变天空。例如，把森林
整体转化为积雪冬境——土地覆雪、树木覆霜、岩石和建筑结冰、空气出现寒雾、
日光变为冬季冷光；这个例子只说明变化的范围和强度，必须结合实际输入重新创作，
不得机械照抄。

全场景视觉重构是“同一张地图的整体换肤”，不是换地图。必须严格保持原视频的
地形高度与轮廓、空间拓扑、道路和地面可通行区域、水岸边界、碰撞与物理属性；
所有既有物体的锚点、数量、尺寸、朝向、开口和遮挡关系不变；主体身份、根运动、
动作时序、相机轨迹和最终落点不变。允许既有物体被积雪、冰霜、湿润、风化或其他
符合目标环境的材质状态覆盖，但不得借换肤增删或挪动地标、改变几何结构和可通行性。
其余四条继续自由设计不同类型的大型变化，不要把五条都写成全场景换肤。

每条事件都要满足：

1. 强场景关联：直接利用对应画面中真实可见的主体、完整标志物、地貌、材质、
   天气或文化气质；删除场景名后仍可套用到多数场景的通用特效不合格。
2. 大而易懂：普通用户能一句话复述发生了什么，变化覆盖主体、环境或天空的
   主要画面区域，具有持续、清晰、电影感强的前后差异。
3. 合理连续：写清变化前、传播方向、材质反应、完成状态和结束方式；同一视频
   的第二条事件承接第一条完成后的状态，不得无解释重置。
4. 保持空间：不得改变地形、道路、建筑结构、可通行区域、镜头路径、角色根运动、
   遮挡和实体数量。可以改变既有主体外观、既有环境的视觉材质状态，或生成短暂
   天气、能量与自然体积效果。
5. 动作独立：事件由 Host 秒数触发，不依赖行走、跳跃、转向、攻击、按键或镜头动作。
6. 声音仅包含与事件同步的环境音和效果音；无音乐、对白、旁白、歌声。

禁止新增或删除人物、动物、建筑、载具和其他持久实体；禁止文字、字幕、Logo、
水印、界面和时间码。每个主要变化在 1.5–4.0 秒完成。

## 输出

只输出 JSON，恰好五个 `events`，严格遵循 Host 槽位顺序。不要输出 `id`、
`windowIndex`、`globalSeconds`、`segmentRelativeSeconds`、`actionCoupling` 或
`eventPrompt`，这些由 Host 补齐。每个元素仅使用以下字段：

```json
{
  "targetNames": ["对应画面中真实存在的目标"],
  "eventClass": "subject-transformation | ability-manifestation | environment-transformation | atmospheric-spectacle",
  "magnitude": "large-scale",
  "frameImpact": {
    "scope": "subject-dominant | environment-dominant | sky-dominant",
    "coverage": "large",
    "contrast": "dramatic"
  },
  "dominantChange": "该场景专属、最醒目的大型变化",
  "targetContext": "目标在对应视频和图片中的位置、关系与基础状态",
  "beforeState": "事件前状态",
  "transitionDescription": "连续、有方向、层次和材质反应的过程",
  "afterState": "完成后的清晰状态",
  "spatialContinuity": "必须保持不变的空间、遮挡、实体和拓扑",
  "audioDescription": "同步环境音与效果音",
  "negativeConstraints": "该事件特有的禁止事项",
  "timing": {
    "transitionDurationSeconds": 2.5,
    "ending": "hold | fade | settle",
    "endingDurationSeconds": 0
  }
}
```
