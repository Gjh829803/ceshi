# Generated preset snapshots

Generated by `asset-library/tools/presets.mjs` with the engine's explicit
`presetAuthoringContext()` callback. Selection lives in `config/integrations/subjects.json`;
content geometry lives in library subjects; tuning and cameras live in `config/presets/subjects.json`.
Run `pnpm content:sync` after changing either authority; `pnpm content:check` verifies exact bytes.

These package-local files support static browser imports and Node package exports.
They are build artifacts, never an editable parameter authority. Scene placements
and optional user profile overrides live in their separate consumer config files.
