# Humans

Use the permitted supplied visible human model, compatible rig and motions for
players, NPCs and riders. Keep one person instance across movement and riding.
Select a model from this page's assetIndex and read its assets_describe entry for
resources, clip mappings, dependencies and limitations. Do not redraw the human.

| Need | Read next |
| --- | --- |
| Walk, run, jump, crouch, crawl or swim | [Movement](movement.md) |
| Slide, roll, vault or climb in the environment | [Scene actions](actions.md) |
| Pick up, carry, put down, sit or stand | [Interactions](interactions.md) |
| Bind the model, controller, camera, rider or NPC | [Integration](integration.md) |

Start with creator_get_examples({topic:'getting-started'}) for a minimal human
binding. Read only abilities required by the user request; the library is not a
checklist of gameplay to add.
